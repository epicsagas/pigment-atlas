## Overview

```mermaid
timeline
    title Refik Anadol key timeline (1985 to 2026)

    2012 : Enters UCLA DMA, develops Infinity Room
    2014 : Visions of America - Amériques (WDCH) : Refik Anadol Studio founded
    2015 : Infinity Room unveiled (Istanbul Biennial)
    2016 : First Google AMI residency
    2017 : Wind of Boston : Archive Dreaming (SALT, 1.7 million documents)
    2018 : Melting Memories : WDCH Dreams (LA Phil centennial)
    2019 : Machine Hallucinations - NYC : Latent History (Fotografiska) : Lumen Prize Gold
    2020 : Quantum Memories (NGV) : First NFT
    2021 : Machine Hallucinations - Nature Dreams : Casa Batlló residency
    2022 : Living Architecture - Casa Batlló : Unsupervised (MoMA opening)
    2023 : Living Paintings (Jeffrey Deitch) : Unsupervised enters MoMA collection : Machine Hallucinations - Sphere
    2024 : Large Nature Model (Davos) : Echoes of the Earth (Serpentine) : LNM Coral (UN)
    2025 : Living Architecture - Gehry (Guggenheim Bilbao) : Biophilia (Venice) : Messi data sculpture : TIME100 Impact Award
    2026 : DATALAND opens (June 20) : Machine Dreams - Rainforest
```
